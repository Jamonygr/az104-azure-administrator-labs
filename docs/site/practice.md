## Your learning record

The rounded percentage score is saved only in this browser. Grading does not
change lab status, deployment validation, or cleanup results. Labs 00, 26, and
27 are hands-on only and have no question bank.

Use [Learner progress](learner-progress.md) to export a backup or import an
existing record. These original practice questions support learning; they are
not Microsoft exam questions. See the [assessment guide](../assessment-guide.md)
for the mastery thresholds and how to review the mapped tasks.
