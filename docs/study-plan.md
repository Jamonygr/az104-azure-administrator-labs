# Suggested study plan

Use the labs in order for a first pass, then repeat weak domains using the question bank and capstones.

| Week | Focus |
|---:|---|
| 1 | Lab 00 and identity/governance Labs 01–03 |
| 2 | Identity/governance Labs 04–05 and Storage Labs 06–07 |
| 3 | Storage Labs 08–09 and IaC Lab 10 |
| 4 | Compute Labs 11–14 |
| 5 | App Service Labs 15–16 and Networking Labs 17–18 |
| 6 | Networking Labs 19–21 |
| 7 | Monitoring/recovery Labs 22–25 |
| 8 | Capstones, objective-map review, and timed question-bank revision |

Do not count a lab as complete until deployment validation and post-cleanup validation both pass. On each 50-question assessment, 43–50 indicates mastery, 35–42 requires targeted task review, and 0–34 means repeat the mapped guided work before retesting.

## Exam readiness

After the capstones and a full question-bank pass:

1. Take [Microsoft's official AZ-104 practice assessment on AI Skills Navigator](https://aka.ms/AZ104-PA) (sign-in required). Microsoft states that the legacy practice assessment on Microsoft Learn is no longer being updated, so prefer the AI Skills Navigator experience.
2. Map every missed practice-assessment topic back to its objective in the [objective map](objective-map.md) and repeat the mapped lab task rather than memorizing the item.
3. Re-open [Microsoft's AZ-104 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104) before booking. This repository is aligned with the blueprint version recorded in the [objective map](objective-map.md); if Microsoft publishes a newer skills list or a change log, treat that page as authoritative and check the [verification notes](research/az-104-blueprint.md#verification-notes) for this repository's status.

The repository's 1,250 questions are original and are not derived from any Microsoft practice assessment; use both together rather than treating either as a predictor of live exam items.
